# Akniga: первая итерация парсера и тестовая среда

## Что реализовано

`AknigaProvider` реализует общий `BookProvider`. Он обходит HTML-каталог от
`https://akniga.org/` по ссылкам «Следующая страница» до последней страницы.
Публичный документированный API каталога не найден; реализация использует HTML,
не обращается к `/ajax/`, не исполняет JavaScript и не загружает аудио.

Карточки списка уже содержат название, автора, чтеца, обложку, серию и длительность.
Обычно отдельный запрос книги не нужен. Если авторы/чтецы сокращены до «и др.»
или обязательных полей не хватает, адаптер запрашивает полную страницу книги.
Метод `book(url)` также позволяет проверить отдельную страницу.
Редакционные подборки, вставленные в каталог с тем же базовым CSS-классом, распознаются
по отдельному маркеру и ссылке `/collection/` и не считаются книгами.

| Поле | Источник |
| --- | --- |
| `externalId` | Числовой `data-bid`, сохраняется строкой. `data-id` / `data-target-id` относятся к публикации и не используются как ID книги |
| `bookUrl` | Основная ссылка карточки, на странице книги — canonical URL; это страница портала, а не ссылка на аудио |
| `title` | Заголовок карточки без префикса автора; на странице книги — `.caption__article-title` |
| `author`, `narrator` | Ссылки авторов и исполнителей внутри карточки или основного `article.book--page` |
| `coverUrl` | Обложка карточки; на странице книги — `og:image` с резервным вариантом из заголовка |
| `series` | Название серии без отображаемого номера книги в конце, например `Аномальные территории (1)` → `Аномальные территории` |
| `durationSeconds` | Русский текст длительности, переведённый в секунды; точность ограничена значением, опубликованным сайтом |

Несколько авторов/чтецов записываются через запятую, без повторов, в порядке сортировки
имён без учёта регистра. Это делает ключ дедупликации независимым от порядка ссылок
на портале. Неизвестные обложка, серия и длительность остаются `null`.

Клиент создаётся через `createAknigaHttpClient()`; владелец должен закрыть его через `use`
или при остановке приложения. Запросы последовательные, с паузой в одну секунду
перед каждым новым запросом. Временные сетевые ошибки, `429` и `5xx` повторяются до двух
раз; поддерживается `Retry-After` в секундах и формате HTTP-даты. Таймаут запроса —
30 секунд, подключения — 10 секунд. Редиректы автоматически не выполняются.

## Защита от неполного обхода

- Неверная разметка, HTML проверки браузера, неожиданный HTTP-статус или Content-Type
  завершают поток ошибкой. Неизвестная пустая страница не считается пустым каталогом.
- Проверяются числовой ID, последовательность страниц, наличие навигации и согласованность
  кнопки «Показать ещё» со ссылкой следующей страницы.
- Повтор ID внутри страницы считается ошибкой. Повторы между страницами из-за сдвига
  каталога пропускаются; наружу каждый ID выдаётся один раз.
- Страница без новых ID, цикл пагинации и превышение защитного лимита в 20 000 страниц
  завершают импорт ошибкой. Лимит не означает успешное завершение частичного каталога.
- ID полной страницы обязан совпадать с ID карточки, которая привела к её загрузке.
- Отмена корутины прекращает обход. При работе через `CatalogSynchronizer`
  незавершённые данные не публикуются: это обеспечивает контракт сессии импорта.

Адаптер пока не подключён к `oneBookModule`: БД и фоновое расписание остаются отдельными
этапами. Лаборатория ниже не меняет `catalog.json`, библиотеку или прогресс.

## Автоматические тесты без сети

Из корня проекта, PowerShell:

```powershell
.\scripts\gradle.ps1 :server:aknigaTest
```

Полная серверная регрессия:

```powershell
.\scripts\gradle.ps1 :server:test
```

`AknigaHtmlParserTest` проверяет извлечение полей, несколько авторов, относительные ссылки,
длительность, отсутствие необязательных полей, изменённую разметку и пагинацию.
`AknigaProviderTest` использует Ktor MockEngine: проверяет двухстраничный обход,
дозагрузку полной карточки, повторы, лимит страниц, `429`/`5xx`, ошибки, отмену и
взаимодействие с координатором импорта. Реальная сеть в этих тестах не используется.

Фикстуры находятся в `server/src/test/resources/akniga/`.
Это небольшие HTML-примеры на основе разметки, проверенной 2 ноября 2026 года:
оставлены только нужные метаданные, удалены описания, комментарии, реклама и скрипты.
Двухстраничный каталог и пути изображений адаптированы для автономного сценария.
Они не являются полной копией каталога сайта.

Отчёты Gradle: `server/build/reports/tests/aknigaTest/index.html`
и `server/build/reports/tests/test/index.html`.

## Лаборатория ручной проверки

По умолчанию выполняется полный обход небольшого каталога из фикстур и печатаются
три JSON-записи. Доступ в интернет не нужен:

```powershell
.\scripts\gradle.ps1 :server:aknigaParserLab
```

Разобрать сохранённый HTML книги локально:

```powershell
.\scripts\gradle.ps1 :server:aknigaParserLab '-PaknigaFile=server/src/test/resources/akniga/book-series.html' '-PaknigaUrl=https://akniga.org/tarasov-roman-artefakt'
```

Разобрать сохранённый HTML каталога локально и вывести ссылку продолжения:

```powershell
.\scripts\gradle.ps1 :server:aknigaParserLab '-PaknigaMode=catalog' '-PaknigaFile=server/src/test/resources/akniga/catalog-page1.html' '-PaknigaUrl=https://akniga.org/'
```

В этом режиме сокращённые карточки выводятся с `requiresDetails: true` без сетевой дозагрузки.
Параметр `aknigaUrl` задаёт исходный адрес сохранённой страницы, чтобы правильно разрешать
относительные ссылки и определять номер страницы. Файлы читаются как UTF-8.

Проверить одну настоящую страницу — выполняется сетевой запрос:

```powershell
.\scripts\gradle.ps1 :server:aknigaParserLab '-PaknigaUrl=https://akniga.org/tarasov-roman-artefakt'
```

Проверить первые пять книг настоящего каталога:

```powershell
.\scripts\gradle.ps1 :server:aknigaParserLab '-PaknigaLimit=5'
```

Допустимый лимит лаборатории — от 1 до 100 записей. Это намеренно ограниченное превью,
оно отменяет дальнейший обход через `take()` и **не считается полной синхронизацией**.
Ошибки завершают Gradle-задачу с ненулевым кодом. Сетевые режимы не входят в автотесты.

## Что проверять в следующих итерациях

- Новые варианты разметки, платные и закрытые книги, сборники, несколько исполнителей.
- Полный продолжительный обход и поведение каталога, когда во время обхода добавляются книги.
  HTML-пагинация не предоставляет согласованный снимок: между страницами возможны сдвиги.
  Первая версия убирает повторы, но не гарантирует отсутствие пропусков при таком сдвиге.
  До включения деактивации источников в БД потребуется сверка полноты обхода.
- Отдельная поддержка воспроизведения, если она понадобится: `bookUrl` пока ведёт на сайт.

Источники разметки: [каталог](https://akniga.org/),
[книга с серией](https://akniga.org/tarasov-roman-artefakt),
[книга с несколькими авторами](https://akniga.org/strugackiy-arkadiy-strugackiy-boris-bufet-mezhplanetnikov).
Ограничения обхода и адрес sitemap опубликованы в [robots.txt](https://akniga.org/robots.txt).

## Полный файловый экспорт

Для длительного полного обхода добавлен отдельный `AknigaCatalogExporter`. Он сохраняет
каждую обработанную страницу атомарно и умеет продолжать с последней сохранённой страницы.
Рабочий каталог сервера при этом не меняется.

```powershell
.\scripts\gradle.ps1 :server:installDist
.\scripts\start-akniga-export.ps1
```

Процесс Java запускается в фоне, без окна и без ограничения числа книг.
Интервал запросов и повторы совпадают с настройками провайдера. По умолчанию результат
сохраняется в `data/exports/akniga/`:

- `progress.json` — статус, PID, число страниц, сохранённых книг и ошибок, адрес продолжения.
- `pages/000001.json`, … — опубликованные страницы с метаданными и явными ошибками отдельных книг.
- `run-*.log`, `run-*.err.log` — журналы запуска.
- `books.jsonl` — объединённый результат без повторов внешнего ID, формируется после полного обхода.
- `failures.jsonl` — неразобранные книги, формируется после полного обхода.

Проверить прогресс:

```powershell
Get-Content data/exports/akniga/progress.json -Raw | ConvertFrom-Json
```

При ошибке каталога процесс останавливается со статусом `FAILED`, сохраняя страницы.
Повторный запуск той же команды продолжает с сохранённого адреса. Блокировка файла
предотвращает одновременную запись двумя процессами. После успешного завершения для нового
обхода нужно выбрать новую папку: `-ExportDirectory 'data/exports/akniga-next'`.

Ошибки отдельных книг сохраняются вместе со страницей и не препятствуют обходу следующих
страниц. При наличии таких ошибок итоговый статус — `COMPLETED_WITH_ERRORS`, код выхода
ненулевой: такой результат нельзя считать полным успешным импортом. Возобновление готового
обхода пересобирает результаты, но не повторяет разбор отдельных отклонённых книг.
